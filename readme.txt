CoffeePOS WooCommerce POS plugin foundation (Phase 00).

== Description ==

This release contains the project foundation only:

- Composer PSR-4 bootstrap
- environment and dependency checks
- activation/deactivation/uninstall foundation
- migration and settings foundation
- POS route/template/asset foundations
- REST namespace and health endpoint foundation

Business features are intentionally out of scope in this phase.
